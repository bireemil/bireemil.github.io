# bireemil.github.io

Personal academic website, built with Jekyll (based on [Academic Pages](https://github.com/academicpages/academicpages.github.io) / Minimal Mistakes).

## Running locally

```bash
bundle install
jekyll serve -l -H localhost
```

Site will be served at `localhost:4000`.

## Using Docker

```bash
docker compose up
```

Site will be served at `localhost:4000`.
